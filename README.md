# PetMatch

Plataforma de adoção responsável com matching por estilo de vida, verificação do adotante e suporte pós-adoção.

## Origem

Nascido como protótipo vencedor no hackathon Coday (projeto acadêmico MIAUmigos).
Continuei o desenvolvimento de forma independente, com nova identidade, foco de produto e evolução para um MVP usável.

## Problema

Alto índice de devolução em adoções e pouca compatibilidade entre tutores e pets.

## Solução

- PetMatch Score (compatibilidade por estilo de vida)
- Verificação do adotante
- Acompanhamento pós-adoção (90 dias)
- Ferramentas para ONGs e protetores

## Stack atual

HTML, CSS, JavaScript (protótipo de interface)

## Em evolução

Auth, CRUD de pets, quiz de matching com persistência e deploy.
